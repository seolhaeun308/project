# 3D 적층 반도체 내부 열 확산(Thermal Bottleneck) 시뮬레이터

## 1. 프로젝트 주제 및 문제 정의
* **주제:** 2차원 열 확산 방정식(Heat Equation) 수치해석을 통한 반도체 내부 온도 분포 시각화
* **해결하려는 문제:** 차세대 3D 수직 적층 반도체(3D IC)에서 소자가 밀집함에 따라 발생하는 열 병목 현상(Thermal Bottleneck) 문제. 열이 방출되지 못하고 갇히는 현상을 시뮬레이션하여 칩 파손을 방지하고자 함.
* **대상 사용자:** 차세대 반도체 소자 구조를 설계하고 발열 위치를 예측하려는 반도체 TCAD 및 소자 연구원.
* **기존 방식과의 차별점:** 무거운 상용 TCAD 프로그램 대신, 고교 물리와 미적분 수준의 유한차분법(FDM)을 적용하여 직관적이고 가벼운 발열 시각화 도구를 제공함.

## 2. 주요 기능 (함수 분리 설계)
1. `set_chip_layout()`: 칩의 크기 및 열원(핫스팟)의 위치, 온도 초기값 설정
2. `calculate_heat_diffuse()`: 유한차분법(FDM)을 이용한 시간에 따른 열 확산 방정식 계산
3. `plot_thermal_heatmap()`: 계산된 온도 분포 결과를 Matplotlib을 이용해 2D 히트맵으로 시각화

## 3. 화면 설계
* **터미널(CLI):** 격자 크기, 열전도율(alpha), 시뮬레이션 시간 등 변수 입력
* **그래픽(GUI):** 시간에 따른 온도 변화를 보여주는 2D 컬러 히트맵 창 출력
